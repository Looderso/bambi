bambi for Windows: VST3 and CLAP, x64

1. Copy the plugins into your plugin folders (this needs administrator rights):
     VST3\*.vst3  ->  C:\Program Files\Common Files\VST3\
     CLAP\*.clap  ->  C:\Program Files\Common Files\CLAP\

2. These alpha builds are not signed, so Windows may warn about them when you unpack the zip. The plugins
   themselves install and run normally.

3. Restart your host and rescan its plugins.
